# ACADEMIX 2.0 — User Guide

## Daily Workflow for Teachers
1. **Login:** Access with your teacher credentials.
2. **Attendance:** Open *Attendance* $\rightarrow$ select your assignment and date $\rightarrow$ mark status (`P`, `O`, `E`, `U`) $\rightarrow$ Save.
3. **Monthly Grid:** Open *Monthly Grid* to review or export the full 1..31 days landscape matrix.
4. **Grades:** Open *Gradebook* $\rightarrow$ select assignment & period $\rightarrow$ enter numeric grades. You have 24 hours to modify entries.
5. **Grade Change Requests:** If a grade is locked past 24h, submit a Request for administrative approval.

## Workflow for Administrators
1. **Expediente / Student Records:** Navigate to *Students* $\rightarrow$ click any student to open the 10-tab dossier.
2. **Official Reports:** Open *Report Center* to issue Progress Reports, Report Cards (RP 26-27), or Transcripts.
3. **Approvals:** Review pending *Grade Change Requests* and *Scholarship Applications*.
